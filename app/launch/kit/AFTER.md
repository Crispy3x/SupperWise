# After launch: what to measure, and what to do about it
**L+1:** crashes (Xcode Organizer); the first reviews (reply to every one); top support emails.

**L+7:**
- **Funnel:** App Store Connect › Analytics: impressions → product page views → downloads, by source.
  - Low impressions: change keywords (keywords.md).
  - Many views, few downloads: change screenshot panel 1. Run the PPO test in experiments.md.
- **Trials:** trial starts and conversions (Subscriptions).
- **Content:** log numbers for batch 1, run `winners`, then build batch 2.

**L+14:**
- Conversion rate and the trial-to-paid rate.
- Write the next update's What's New: specific, not "bug fixes".
- Promo text for the next four weeks.
- If you have an ad budget, start with Apple Ads on "budget meal planner" (the launcher's Grow G1).
